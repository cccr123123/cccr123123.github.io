# 倒计时台 v2 · 改了什么

原版 `index.html` 一个字没动。这一版是 `index-v2.html`，双击就能开（同目录的 `assets` 要一起带着）。

## 一、视觉：只做统一，不换风格

底子没推翻——描边贴纸、玻璃卡片、深海蓝、大小肥鱼都还在。动的是这些：

| 位置 | 改了什么 |
| --- | --- |
| 顶部工具条 | 导出 / 导入 / 清理收进「更多」菜单，顶栏只剩图标条 + 一个粉色主按钮 |
| hero | 加了一行「今天 · 周几 · 农历 · 节气」；标题字阶收到统一刻度 |
| 卡片 | 编辑 / 复制 / 存卡 / 删除换成图标按钮（悬停有文字提示）；时分秒压成次要信息，进度条下加一行两端对齐的说明 |
| 背景 | 12 层装饰按重要性分了三档强度，手机自动减半 |
| 手机 | 顶栏不换行、hero 居中、卡片单列、底部加悬浮「+」；筛选和搜索框各占一行 |
| 文案 | 只清了两处说明腔（页脚的数据说明和时区），主人写的句子一律没碰 |

字阶、间距、阴影都收进了 CSS 变量（`--fs-*` / `--sp-*` / `--surface-*`），以后调数值只改一处。

## 二、新增功能

| 功能 | 怎么用 |
| --- | --- |
| 沉浸时钟 | 顶栏 ⛶ 或按 `F`。全屏只剩时间、农历节气、最近的一个日子；双击 / `Esc` / 右上角 ✕ 退出 |
| 搜索 | 工具条里的搜索框，按 `/` 直接聚焦。搜标题、日期、星期都行 |
| 农历 / 节气 | hero 里常显。农历用浏览器内置的中国历（不塞数据表），节气按太阳视黄经现算 |
| 背景音 | 顶栏喇叭图标开关；音色和音量在「更多」里选（海浪 / 雨声，都是 WebAudio 现场合成的，不占音频文件） |
| 配色 | 「更多 → 配色」四个色块：深海（默认）/ 晴海 / 深海夜 / 樱花粉。选择记在本地 |
| 桌宠心情 | 悬停桌宠看心情条；点旁边的小鱼干喂食，+8 点，两秒半冷却。心情每小时自然掉 1.6 点，低于 30 会变蔫 |
| 纪念卡 | 卡片上的下载图标，导出一张 1080×1440 的 PNG |

## 三、快捷键

`F` 沉浸时钟　`Q` 静谧模式　`/` 聚焦搜索　`N` 新增日期
`1` `2` `3` 全部 / 未来 / 已过　`T` 换配色　`M` 背景音开关　`E` 导出 JSON
`?` 打开快捷键面板（也是唯一需要记的一条）　`Esc` 退出沉浸 / 关面板

输入框里按这些键不会误触。

## 四、数据

| 键名 | 存什么 |
| --- | --- |
| `dshwhale.countdowns.v1` | 日期列表（**和原版共用**，两边能互相读） |
| `dshwhale.theme.v1` | 配色 |
| `dshwhale.sound.v1` | 背景音音色与音量 |
| `dshwhale.pet.mood.v1` | 桌宠心情值和时间戳 |
| `dshwhale.pet.pos.v1` | 桌宠被拖到的位置（原版就有） |

原版的导入 / 导出照常能用，两个版本的数据可以互相导。

## 五、几个说明

- **背景音要手动点一下才响**：浏览器不允许页面一打开就自动出声，这是浏览器策略不是 bug。
- **纪念卡存在下载文件夹**，文件名是「倒计时-标题-N天.png」。Safari 可能拦下载，换 Chrome / Edge 稳一点。
- **节气是现算的**，跟万年历对过（2026 立冬 11/7、冬至 12/22 都对得上）。
- **系统开了「减少动态效果」时**，桌宠待机视频不自动播（尊重设置），点她还是会有反应。
- 单文件版（`倒计时-单文件版.html`）没重做，v2 还是依赖同目录的 `assets`。

# 第二轮：往「助手」方向收

主人反馈「看着挤、乱，动画太脉跳，想突出计时」。这一轮只做减法，立绘和那句「交给深海保管」都没动。

## 一、首屏加了一条助手条

hero 下方横跨一整条：

| 位置 | 内容 |
| --- | --- |
| 左 | **现在几点**：大号时钟 + 今天的日期和星期 |
| 中 | **下一个**：日程名 + 还剩几天 + 剩余「时:分:秒」+ 一条进度线，右边写目标时刻 |
| 右 | 在册几条 / 合计还剩多少天 |

原来那三个统计块（在册日期 / 最近一个 / 合计剩余）的信息已经并进来了，不再单独占一行。

## 二、减掉的东西

| 减了什么 | 为什么 |
| --- | --- |
| 背景装饰 12 层 → 5 层 | 雨丝、星点、鲸鱼剪影、蝴蝶、涂鸦、涌浪、射线全部撤掉，只留海水 / 颗粒 / 雾 / 泡泡 / 右下远景 |
| 全屏呼吸动画 | `.sky` 那条对整屏做 filter 的动画停掉（最费性能，也最容易"脉跳"） |
| 卡片和 hero 的背景模糊 | 十几层 `backdrop-filter` 是滚动发涩、画面发糊的主因，改成更实的半透明 |
| 顶栏那个小时钟 | 和助手条重复，删掉 |
| 桌宠的一部分存在感 | 缩小了，鼠标移进列表时自动淡到 26%，不挡数字 |
| 桌宠的碎嘴 | 只有「记下一笔 / 改好啦 / 小鱼干 / 卡片做好了」会说话，其余操作静默 |

装饰层 17 → 8，运行中的循环动画 5 → 1（只剩挂饰那条鲸鱼的尾巴在摆）。

## 三、更像助手的几处

- **最近的那个日程自动标出来**：卡片一圈青色光，列表里也排在最前
- **剩余时间精确到时分**：卡片上写「还有 7 天 8 小时」，助手条写「7 天 08:48:27」，两边对得上
- **快捷键补全**：`?` 面板、`1` `2` `3` 切筛选、`T` 换配色、`M` 静音、`E` 导出
- **一屏放下**：1366×768 的笔记本实测首屏不用滚

## 四、想调的话

| 想改 | 改哪儿 |
| --- | --- |
| 助手条太高/太矮 | 样式里搜 `.console` 的 `padding` |
| 装饰还想再少 | `body` 上已经有 `quiet` 类，或者直接在样式里把 `--deco` 调低 |
| 桌宠想完全不挡 | 搜 `.pet{`，把 `opacity` 调到 `.55` 左右 |
| 想让某类操作也让桌宠说话 | 搜 `SAYABLE`，往那个正则里加关键词 |
