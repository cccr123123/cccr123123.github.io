# 雨夜便利店 · 可以走进去的那家

用 **three.js** 做的第一人称雨夜便利店：可以走进店里、逛货架、拿东西、到收银台结账、和店员说话。整条街、雨、积水、商品包装、人物、连声音都是程序化生成的 —— 没有一张外部图片、没有一段外部音频、没有外部模型。

## 打开方式

直接双击 **`index.html`**。不需要服务器、不需要联网。

> 也可以 `npm run preview` 起本地服务（http://127.0.0.1:8123/）。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 按住鼠标拖动 | 环顾四周（不锁定鼠标） |
| W A S D / 方向键 | 走动（Shift 小跑） |
| E | 拿商品 / 结账 / 和店员说话 / 推进对话 |
| 数字键 1–5 / 点选项 | 选择对话选项 |
| Q | 把刚拿的东西放回货架 |
| Esc | 结束对话 |

**买一次东西：** 走到货架前，看着商品按 E 拿进篮子 → 走到收银台按 E → 店员会一件件扫码（顾客屏上数字滚动）→ 按 E 付款 → 找零、打印小票。

**和店员说话：** 走到收银台后面看着店员按 E。话题树有 15 个节点、4 个分支（推荐商品、聊雨、问关东煮、问一个人看店……）。选「来两串」她会真的把两串关东煮放进你的篮子。

## 场景里有什么

- **12 米宽的店面**：招牌灯箱「星野マート / 24H」、红白条纹遮阳篷、自动门（靠近自动滑开）、「珈琲」侧招、玻璃上的促销海报
- **可走动的店内**（13 × 11 米）：四排双面货架 + 五条通道、后墙饮料冷柜、收银台（POS、顾客显示屏、扫码枪、找零盘、小票机）、关东煮锅、烤肠保温柜、杂志架、购物篮堆、复印机、墙面海报、天花板灯管与格栅
- **16 种商品**：饭团、便当、三明治、拿铁、绿茶、可乐、矿泉水、杯面、薯片、巧克力、菠萝包、牛奶、冰淇淋、关东煮……包装上的字和图全是 canvas 现画的
- **三个角色**：店员小葵（低多边形动漫风，会转身看你、说话时动嘴、扫码时抬手臂）、在货架间走来走去的顾客、门口撑着透明塑料伞躲雨的人影
- **店外**：湿漉漉会反射招牌的柏油路、雨丝、地面涟漪、自动贩卖机、路灯、电线杆、远景楼群、偶尔的闪电和闷雷
- **声音**：程序化雨声（进店自动变小）、店内轻音乐、门铃、脚步、扫码「嘀」、硬币找零

## 技术上做了什么

- **第一人称**：自己写的控制器（不锁指针、加速度、圆柱 vs AABB 碰撞、头部起伏、脚步回调）
- **交互**：视线射线 + 距离/夹角评分挑选目标，瞄准时准星变圈、显示「按 E 拿什么」
- **湿地面**：改写 `Reflector` 的 shader，双尺度水洼遮罩 + 三层雨滴涟漪 + 菲涅尔反射 + 场景雾
- **雨**：`LineSegments` + 自定义顶点着色器，雨域跟随相机取模循环，屋檐下和伞下自动无雨
- **商品**：数据驱动的包装贴图生成 + 十种低模几何（三角饭团、扁便当盒、罐、瓶、杯面、薯片袋……）
- **角色**：纯几何体拼的低多边形动漫小人，带关节和简单状态机（呼吸、转身、点头、说话、扫码）
- **后处理**：泛光 → ACES 色调映射 → 电影调色（饱和、暗角、颗粒、色差、闪电泛白）
- **声音**：WebAudio 合成雨声（三层噪声滤波 + LFO）、店内琶音、十几种交互音效

## 项目结构

```
index.html              页面 + HUD（准星/购物篮/对话/小票/开始页）
dist/rainy-store.js     构建产物（three.js 已打包，约 620 KB）
src/main.js             入口：渲染器、灯光、场景组装、主循环、事件
src/exterior.js         店的外壳：招牌、遮阳篷、橱窗、门口杂物、撑伞的人
src/interior.js         店内：地板、吊顶、灯、四排货架 + 商品、冷柜、海报
src/fixtures.js         收银台、POS、关东煮、热食柜、杂志架、自动门
src/goods.js            商品数据 + 包装贴图 + 几何
src/npc/character.js    低多边形角色构建与动画
src/player/fpControls.js 第一人称控制器
src/systems/interact.js 视线交互
src/systems/shop.js     购物篮 + 结账流程
src/systems/dialogue.js 对话树 + 打字机
src/ui/hud.js           HUD 逻辑
src/ground.js           湿地面反射 shader
src/street.js           天空、楼群、路灯、电线杆、贩卖机
src/rain.js             雨
src/post.js             后处理链
src/audio.js            程序化声音
src/textures.js         所有 canvas 贴图
```

## 想改点什么

改完 `src/` 后跑 `npm run build` 重新打包。

- 商品与价格 → `src/goods.js` 的 `GOODS`
- 对话内容 → `src/systems/dialogue.js` 的 `DIALOGUE`
- 货架摆放 → `src/interior.js` 的 `ROWS` / `POOLS`
- 店内亮度 → `src/interior.js` 的 PointLight、`src/main.js` 的 `ambient`
- 泛光 → `src/post.js` 的 `UnrealBloomPass(...)`
- 玩家速度/视线灵敏度 → `src/player/fpControls.js`

### 调试参数

在网址后面加：

- `?auto=1` 跳过开始页直接进入
- `?pos=x,z,yaw` 指定出生点和朝向（yaw 单位弧度，0 = 朝店内）
- `?demo=basket` / `?demo=checkout` / `?demo=receipt` / `?demo=dialogue` 自动演示对应流程

## 已知限制

- 对话是**预设话题树**（纯前端、离线可跑）。想接真 LLM 的话，需要额外加一个本地代理（页面不能直接拉起本地模型），`src/systems/dialogue.js` 里的节点结构可以直接替换成接口调用。
- 人物的手部动画比较简化（没有骨骼绑定），扫码、挥手是几个关节的插值。
- 桌面 1080p 目标是 60fps；如果集成显卡偏卡，可以先把 `renderer.setPixelRatio` 上限调到 1.0，或关掉 `src/post.js` 的泛光。
